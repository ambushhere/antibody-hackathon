# External HER2 SPR transfer protocol

Frozen on 14 November 2026 before external outcome scoring. This is a retrospective transfer check within the trastuzumab family against human HER2. Cohort sizes and labels were previously inspected. All model parameters, eligibility rules and metrics below are fixed before comparing predictions with outcomes.

## Compatibility and cohorts

The Absci README annotates WT HCDR1 `GFNIKDTY`, HCDR2 `IYPTNGYT` and IMGT HCDR3 `SRWGGDGFYAMDY`. Its reference heavy and light chains match the benchmark's WT VH and VL at their variable-domain prefixes. In the shared WT VH, HCDR1 spans residues 26–33 and HCDR2 51–58. The full IMGT HCDR3 spans linear VH residues 97–109. The model varies residues 99–108, equivalent to characters 3–12 in a same-length HCDR3 with the WT anchors `SR` and `Y`. Admit only canonical 13-residue HCDR3s with both anchors intact. Unsupported lengths and anchor changes stay visible as exclusions. The correspondence is positional on the shared WT reference. Per-variant numbering and alignment are unavailable.

The public methods describe HCDR3-only or HCDR1–HCDR3 inserts in a vector carrying trastuzumab Fab and report high-throughput SPR on captured Fab samples with human HER2 ECD. Full paired sequence and construct identifiers are absent at the CSV row level. The Chinery SPR training inputs carry exact VH and VL checks, while assay construct and conditions are a potential transfer difference. Mark external compatibility as conditional on the study-level Fab provenance. [Absci methods, Cloning and SPR](https://www.absci.com/wp-content/uploads/2023/11/Absci___Unlocking_de_novo_antibody_design.pdf) · [Chinery et al.](https://doi.org/10.1101/2024.03.26.586756)

1. Primary cohort uses `spr-controls.csv`, with both HCDR1 and HCDR2 required to equal WT exactly. Compare scores on the published `Binder` endpoint and separately on reported positive finite KD among binders. A false call without KD stays a binary negative and contributes no KD. Keep an explicit outcome audit for missing, invalid or conflicting data.
2. Secondary cohort uses `zero-shot-binders.csv`. The source describes HCDR3-only designs in the trastuzumab Fab scaffold. HCDR1/HCDR2 are inferred from that method and unavailable for per-row confirmation. Analyze admissible, previously unrepresented windows for KD ranking only, separately from controls. Exclude a selected window that also occurs in a sequence-compatible control, independent of outcome. This binder-selected cohort supplies no binary denominator.
3. The functionality file supplies provenance for a subset and distinguishes original, purified Fab and mAb KD. Audit the links to the selected binder file and the WT reference. Keep these follow-up values out of scoring and avoid counting original KD twice.

Exclude WT and any exact canonical ten-residue match to the 158 ridge fit IDs, the FACS train, validation or test split or the full internal SPR input (including unquantified rows). For every sequence-compatible window including excluded matches, record exact Levenshtein distance to the actual ridge fit IDs, FACS train and FACS validation. Record exact membership in the other internal panels. Within each cohort the unit is one HCDR3 window in its conditional scaffold. Collapse repeated agreeing labels, exclude conflicting labels from both endpoints and combine distinct compatible positive measurements using the median of `−log10(KD nM)` over distinct KD values. Preserve source row references. Unknowns and explicit censoring remain without a numeric target.

## Endpoints and uncertainty

Higher scores favor stronger binding for both models. Use ROC AUC and average precision for binding detection in the control cohort and report the binder fraction as the average precision baseline. For KD use Spearman rho and Kendall tau-b against `−log10(KD nM)` and report direct ridge MAE, RMSE and mean signed error in that scale as descriptive cross-assay diagnostics. FACS and ridge comparisons use exactly the same records per endpoint and include a fixed comparator, negative Levenshtein distance to WT, with no fitted parameters.

Use the existing Levenshtein ≤2 connected-components grouping over all eligible windows across both series and preserve those groups across endpoints and sensitivities. Resample whole groups with replacement, 2,000 draws with NumPy seed 0. Report 95% percentile intervals for the score metrics and paired ridge minus FACS differences for rank and detection metrics. Grouped intervals require at least five observed endpoint groups and at least 90% valid draws for that metric. Undefined draws are counted and excluded. Report largest endpoint group size and leave-one-group-out sensitivity for paired ranking and detection differences. Predeclared sensitivity requires minimum distance ≥3 to SPR fit, FACS train and FACS validation. Include it even when an endpoint is undefined. These intervals condition on the frozen predictions and this selected panel. Model uncertainty, study-level clustering and ascertainment remain outside their scope.

No external labels enter model fitting, calibration, thresholding or shortlist selection. The comparison tests score transfer on measured endpoints. It does not establish unbiased hit rate, cross-target transfer, experimental competition, stability or promotion.
