# HER2 model capability audit

Observed 14 November 2026, 14:01 UTC. This is a read-only audit of the local Apheris RFD4 package and the currently listed Nebius Scientific and JapanFold model APIs. No inference, paid job, weight export or credential change was made by this audit. Provider catalog availability is not evidence that a runtime is ready for a scientific run.

## Findings

- The VM has a cached Apheris RFD4 image for `her2-novel-2026-11-09`. The container exposes the named `her2-novel` generator selector. The image's weight root is selected through `--data-path` or `APHERIS_DEFAULT_WEIGHTS`; the root is expected to contain `flow_checkpoints/` and `ae_checkpoints/`. The absolute path inside the image was not exposed by the available docs or help output, and no environment or weight files were inspected.
- `her2-novel` is an Apheris fine-tune of the antibody RFD4 checkpoint. The organizer guide says its training used pairs of high and low HER2 binders. It reports 100 generated designs from seed 1, with 86% passing its local challenge filter and 6.8 Å median interface error after Protenix refolding. Those are generator and structural results, not measured KD, competition or Tm. The guide does not publish an example-level training manifest, split policy, deduplication record or independent held-out test for either HER2 fine-tune. Leakage is therefore unresolved.
- The local RFD4 container exposes `design`, `finetune` and `metrics`. The documented fine-tune input is a Parquet/CIF structure dataset. The inspected help does not expose teacher logits, a distillation task, an embedding task or the pairwise high/low preference recipe used for `her2-novel`.
- JapanFold lists a generic RFD4 design API and a separate `rf3` structure predictor. Nebius lists a public-upstream RFD4 generator. Neither catalog identifies the Apheris `her2-novel` checkpoint or an import path for it.
- The providers expose structure design, complex prediction, inverse folding, sequence design and a binding ΔΔG prediction. I found no direct thermal ΔTm/Tm prediction operation in the focused catalogs. Binding ΔΔG is not thermal stability.
- Structural confidence is a hypothesis about a modeled pose. Protenix recovered 7/19 WT footprint residues in the split and 3/19 in the domain IV context; RF3 recovered 14/19 but distorted the aligned target and reversed the strong-versus-weak SPR ordering. A separate local OpenDDE-AbAg replicate summary now reports WT recovery of 2, 0 and 5/19 across seeds 42–44, with high target and interface RMSD. Use measured KD for affinity, competition for epitope retention and a thermal assay for Tm.

The user-referenced `ProteinMPNN` label is treated as tentative: it is not in the documented Apheris HER2 pipeline. If ProteinMPNN changes a generated sequence on a fixed backbone, that altered sequence needs a subsequent refold before its structure is evaluated.

### Platform availability is not runtime proof

The Nebius catalog revision observed at 14:01 UTC was `5b78813f7a6b4a4f2e764db7289e138dd90e9584e0614acea23c64e67d9e37a7`, unchanged from the first read. Its `available` and `enabled` fields describe the model catalog. Several scientific models explicitly carry `configured-native-dag-not-a-readiness-claim`; no model job or health probe was run by this audit. JapanFold's model catalog also starts no job, and its response did not publish a weight hash for the hosted RFD4 checkpoint. The shared worktree contains separate OpenDDE-AbAg receipts/results; those are treated as existing evidence, not jobs submitted by this audit.

JapanFold separately lists ESMC and SaProt embedding endpoints. Those are generic protein representations, not embeddings from the Apheris HER2 RFD4 model. A representation endpoint does not provide RFD4's teacher probabilities. The focused Nebius catalog queries for `thermal` and `stability` returned no direct thermal-stability prediction model. `stab-ddg` is the binding-energy service.

## Distillation and licensing boundary

Classical distillation needs teacher probabilities/logits or another explicit teacher target. The local Apheris CLI exposes hard generated designs and native metrics but no such output. The Nebius RFD4 schema exposes `generate` from an annotated CIF and a result artifact; it has no HER2 checkpoint selector or weight-upload field. JapanFold exposes hosted generation and separate generic embeddings, not Apheris model weights. I found no provider-side fine-tuning or RFD4-distillation operation in these selected APIs.

The public upstream RFD4 model card says BSD 3-Clause covers the upstream model and weights, and the upstream license permits source and binary redistribution and modification under its conditions. That is evidence for the public upstream release. It does not establish the license of Apheris's HER2-specific checkpoints, the challenge data used to train them, their generated outputs or a student distilled from them. No separate published license for the Apheris `her2-novel` artifact was found in the VM documentation or selected provider schemas. Its export and distillation rights remain **unknown**. Local image access is not permission to export weights.

The local `finetune` command is a structure-based RFD4 fine-tuning route: it expects a Parquet dataset with referenced CIF structures and antibody region annotations for antibody tasks. It does not document a sequence-only FACS/KD trainer or the high/low pairwise preference objective used for `her2-novel`. A supervised student using FACS/SPR labels would be a separate model-development path, not evidence of direct RFD4 distillation.

## Two high-value experiments

1. **Repeat the HER2 checkpoint comparison with matched sampling.** Compare `her2-2026-11-07` and `her2-novel-2026-11-09` with the same input structure, `sequenceTsrK`, recycle recipe, design budget and three shared seeds. Report unique qualifying designs per attempt, exact challenge-filter outcomes, distances to the known FACS and SPR sequences, and structural diagnostics under one fixed refold protocol. Keep WT, quantified strong SPR and quantified weak SPR as controls. Do not treat FACS-low as an assay-confirmed non-binder. First obtain the training sequence manifest or label the result as potentially overlapping; otherwise the apparent novelty/generalization cannot be called independent. This directly tests whether the 86% one-seed filter rate repeats and separates checkpoint effects from sampling settings.
2. **Back-test StaB-ddG on measured HER2 SPR variants.** Use only quantified, same-length trastuzumab-background variants that can be mapped to the 1N8Z WT complex, including WT and the measured strong/weak controls. Compare predicted binding ΔΔG ordering with measured log KD using sequence-grouped holdouts and the same variant rows for the existing sequence ridge. Record the fixed-WT-backbone limitation because large CDRH3 changes may alter geometry. Failure to order the known strong and weak controls is a stop signal for using this model to rank CDRH3 candidates. Passing would support only a binding-energy hypothesis, never Tm.

Both are proposals only. Provider admissions remain with ROOT. The second needs a provider run; neither was run during this audit.
