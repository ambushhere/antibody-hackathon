# Official event artwork

These original logo files were retrieved on 16 November 2026 from the [AI × Antibodies hackathon website](https://oslo-ai-antibodies-hackathon.vercel.app/#partners). Partner roles were cross-checked against the [organizer's event listing](https://luma.com/16qoctcz).

The artwork identifies the event organizer and partners, not the author of this project. Each brand mark belongs to its respective owner. The event site does not provide a blanket license for these marks; no new license is asserted here.

[sources.json](sources.json) records the exact download URLs (or embedded-image origin), retrieval date, byte lengths and SHA-256 hashes. Logos are preserved as supplied, without redrawing or recoloring. The event site's alt text incorrectly labels the Girls Who ML image as Adaptyv; its adjacent title and event listing identify it correctly.

The assembled wall is generated by [build-event-partners.py](../../../scripts/presentation/build-event-partners.py). The PNG preview uses librsvg:

```bash
source .venv/bin/activate
python scripts/presentation/build-event-partners.py
rsvg-convert docs/assets/event-partners.svg -o docs/assets/event-partners.png
```

The [SVG](../event-partners.svg) retains vector text and embedded source artwork. The [PNG](../event-partners.png) is used in the GitHub README for predictable rendering.
